# Security notes

- Никогда не публикуйте seed phrase, private key, keypair JSON или секреты RPC.
- Используйте отдельные локальные/devnet-кошельки без реальных средств.
- Любая операция с токенами должна проверять signer, mint, token program и связанные token accounts внутри программы.
- Для transfer используйте checked-вариант с decimals из mint.
- Запрещайте нулевые суммы и недопустимые переходы состояния.
- Не используйте общий vault без уникального PDA-контекста сделки.
- Не применяйте `init_if_needed`, пока не доказана защита от повторной инициализации.
- Перед mainnet нужен отдельный security review; этот starter предназначен только для обучения и локальной/devnet-разработки.
